# Amarra · agr20covilha.github.io/amarra

Atalhos da app Amarra (Agrupamento 20 Covilhã, CNE): uma casca por secção que mostra a app em ecrã inteiro com ícone, favicon e barra do iPhone próprios. Não contém dados — a app e os dados vivem no Google Apps Script. Gerado por `ferramentas/atalho-site.js` no repositório da app; não editar aqui.
